# Горки (Rollercoaster)

### Хранение данных
  Основные данные записанные в бинарном файле в формате записи little-endian. 
Данные записаны следующим образом:
  1) в формате float записано значение, которое интерпретируется как значение по оси Oy
  2) индекс значения в общем массиве - значение по оси Ox
В программе данных сохраняются в std::vector.

### Основная задача
  Данные представляют из себя непрерывный график. Пример данных из контрольного примера:
  <img width="1656" height="911" alt="image" src="https://github.com/user-attachments/assets/7fe3b74a-79e1-4da3-af40-037440892e63" />
   В данных хорошо различимы два компонента: уровень шума ("пол") и выпуклые фрагменты разной ширины ("горки"). У каждой "горки" есть левая граница 
(индекс в данных, начиная с которого идет подъем выше уровня "пола") и правая граница (индекс
данных, начиная с которого идет спуск до уровня "пола"). Разница между правой и левой границей 
это ширина горки.
Необходимо при задаваемых пользователем параметрам: минимальная и максимальная ширина "горки" - обнаружить все "горки"
