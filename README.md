# Rollercoaster (Горки)

![C++](https://img.shields.io/badge/C++-17-blue?logo=cplusplus)
![CMake](https://img.shields.io/badge/CMake-3.10+-green?logo=cmake)
![Tests](https://img.shields.io/badge/Tests-Google%20Test-orange?logo=googletest)

Консольная программа для анализа непрерывного графика и обнаружения выпуклых фрагментов ("горок") заданной ширины.

## 📋 Описание задачи

Программа работает с бинарными данными (float, little-endian), которые представляют собой непрерывный график. В данных хорошо различимы два компонента:

- **Уровень шума ("пол")** — базовый уровень сигнала
- **Выпуклые фрагменты ("горки")** — участки графика, поднимающиеся выше уровня пола

Каждая "горка" имеет:
- **Левую границу** — индекс в данных, начиная с которого идет подъем выше уровня пола
- **Правую границу** — индекс данных, начиная с которого идет спуск до уровня пола
- **Ширину** — разница между правой и левой границей

**Задача:** при заданных пользователем параметрах (минимальная и максимальная ширина горки) обнаружить все горки, удовлетворяющие этим условиям.

## ✨ Возможности

- 📊 Чтение бинарных данных в формате float (little-endian)
- 🔍 Автоматическое определение уровня шума
- 🎯 Поиск горок с заданными границами ширины
- 🧪 Полное покрытие тестами на Google Test
- ⚡ Хранение данных в `std::vector` для эффективной обработки

## 🛠 Требования

- Компилятор C++17 или новее
- CMake 3.10+
- Google Test (для запуска тестов)
